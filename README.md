# Лабораторная работа №2. Классы и объекты в Dart
Консольное ToDo-приложение на языке Dart. Демонстрирует основы ООП:
классы, поля, конструкторы, методы, геттеры и статические поля.
Приложение работает в цикле: показывает меню, ждёт команду, выполняет её.

## Ответы на вопросы
### В чём разница между полем класса и обычной переменной в функции?
Обычная переменная живёт только внутри функции и существует, пока эта функция выполняется. Поле класса привязано к конкретному объекту: у каждого экземпляра свои значения, и они сохраняются, пока жив сам объект. То есть поле — это «состояние объекта», а переменная в функции — это временное значение для вычислений.
### Что такое конструктор и зачем он нужен?
Это специальный метод, который вызывается при создании объекта и задаёт начальные значения полей. В Dart называется так же, как класс. Короткая запись: Todo(this.id, this.title) : isDone = false; — this.id сразу записывает аргумент в поле, а : isDone = false задаёт значение поля, которое не передаётся через параметры.
### Зачем нужен @override перед toString()? Что будет если его убрать?
@override говорит, что метод переопределяет метод родителя, и компилятор проверяет, что такой метод там есть — защищает от опечаток. Для toString() родитель — класс Object, от которого неявно наследуются все классы в Dart. Если убрать — код будет работать, но при опечатке в имени компилятор не подскажет, и метод не переопределится.
### Чем статическое поле static int _counter отличается от обычного поля? Сколько копий этого поля существует в программе?
Обычное поле — у каждого объекта своё. Статическое — принадлежит классу целиком и существует в одном экземпляре, сколько бы объектов ни создали. В лабораторной используется как счётчик ID: id = ++_counter — сначала увеличить, потом присвоить.
### Что означает нижнее подчёркивание в _counter?
В Dart _ делает идентификатор приватным для файла: обратиться к _counter можно только из того же файла. Приватность работает на уровне файла, а не класса.
